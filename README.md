# 梁选模式 · DSH 插件

TypeScript / React 插件，目标是保留标准模式的能力与系统提示词，在任务运行期间展示梁文峰语录。

当前阶段完成 **212 条语录结构化** 和 **DSH 内置开发预览面板**。真实“梁选模式”的 preset 注册和实际会话运行状态适配尚未接入；预览不会发送模型请求或修改会话。

## 本地开发

需要 Node.js >= 24.9，以及已安装依赖、完成构建的 DeepSeek Harness 源码。本次适配版本为 `0.2.1-rc.3`。源码默认位于本项目的同级 `deepseek-harness`，可通过 `DSH_SOURCE` 指定其他位置。

```powershell
npm ci --ignore-scripts
npm run build:dev
npm run dsh:install
npm run dsh:start
```

启动后打开终端给出的登录链接，完成本地认证后访问 http://127.0.0.1:41831，在 DSH 侧栏选择“梁选预览”（英文界面为 Liang preview；未固定时在“更多”中）。数据保存在项目内 `.dsh-dev/`，不会安装到日常使用的 Web 或 Desktop profile。端口可用 `LIANG_PORT` 修改。

另开终端执行 `npm run dev` 监听插件源码，生成 `dist/dev/client.js`。DSH 的客户端 HMR 在启用时可接收重建；若未自动更新，刷新测试页面。宿主入口或清单变化后重新运行安装命令并重启测试宿主。

如果源码宿主缺少运行产物，在 Harness 源码目录按该版本的开发说明先执行 `pnpm install --frozen-lockfile` 和 `pnpm run build:artifacts`。宿主脚本与插件脚本各自负责自己的构建。

## 预览功能

- 模拟深度思考、工具执行、回答与任务结束，状态仅在客户端内存中。
- 任务开始时展示第一条；思考、工具执行和输出回答均持续轮播，任务结束时收起。
- 每次展示独立抽取 20～45 秒停留时长，经典分越高通常越久；1× / 5× / 10× 时间倍率。
- 停留时间从正文和落款完成入场后开始，不计入散开与聚拢的动画时间。
- 立即展示、下一句、最短 / 最长文案，以及语录库中的指定文案。
- 点击弹层任意位置或 Esc 关闭；任务仍运行时，等待本条设定的完整时长再弹出下一条。
- 思考、工具、回答之间切换不会重置计时或换句；结束、离开页面清理本轮计时。
- 后台页面暂停，不补弹；减少动态效果模式保留淡入淡出。
- 语录库展示经典分、当前出现分和下一次抽中概率；操控面板展示本次停留时长和倒计时。

原生预览通过 `main` 与 `sidebar.panellist` 插槽挂载。左栏是 DSH 本身，右侧是插件拥有的预览页面；底部操控区是开发功能。当前阶段不覆盖真实聊天页，后续真实会话适配将复用 `QuoteOverlay` 与抽选逻辑。

视觉参数：黑色底层不透明度 60%（40% 透明）；人像与光芒整体不透明度 50%；文字保持不透明。背景入场约 600ms。正文混合单字和短片段，以随机顺序在显示区域中央的横向长方形内散开、漂移，然后聚拢到完整段落的位置。落款“—— 梁文峰”位于文案段落右下角，正文聚拢后从下方 18px 上浮并淡入，耗时约 600ms；短文案的落款随文案宽度对齐。长方形宽为显示区域的 72%（最多 900px），高为 32%（最多 320px）；分区随机分布让文字覆盖边角，避免集中成圆形。正文动画约 2.6～3.4 秒；原地换句保留人像，旧文字先向四周散开。减少动态效果时改用淡入淡出。

随机停留时长按整秒计算：`round(20 + 15 × (classicScore - 1) / 99 + 10 × U)`，其中 `U` 为每次重新抽取的 0～1 均匀随机数。整个范围为 20～45 秒，例如经典分 50 约为 27～37 秒，经典分 100 约为 35～45 秒；高分提高基础时长，同时保留随机浮动。时长只在选中一条文案时计算一次，状态切换或界面重绘不会重新抽取。

## 数据

`asset/quotes/quotes.json` 是运行时数据，数组每项严格只有 `id`、`text`、`classicScore`。ID 根据规范化原句生成，调整顺序不改变 ID。

`asset/quotes/quote-sources.json` 单独保存原文行号、章节、年份、来源编号与原资料的可靠性标签。内容来自用户提供的 Markdown，未独立核验外部出处；B/C 条目保留“流出实录整理”的性质。事实记述、媒体概括、误传示例和核心十句的重复均不入库。只做格式清理，不改写原句。

经典分是编辑权重，不是可靠性评分：代表性金句通常 85–100，普通独立陈述以 50–70 为基础，强依赖上下文的片段降至 35–40。具体人工调整在 `scripts/structure-quotes.mjs` 中，可重新生成与复核：

```powershell
npm run quotes
npm run quotes:check
```

抽选权重为 `classicScore / (1 + 出现分)`。上一条在多条语录时不参与下一次抽取。每次真正开始展示后，所有出现分减一（最低零），选中项加六。选择但被取消不计分；同一展示只提交一次。分数只在客户端内存中，重载清零。

## 构建与分发

- `npm run build:dev` → `dist/dev/`，包名 `dsh-liang-says-dev`，含开发预览面板。
- `npm run build` → `dist/release/`，包名 `dsh-liang-says`，不含模拟器入口。本阶段仅包含共享展示组件，尚不是可发布的完整模式。
- `npm run pack:dev` → 本地测试用 `.tgz`。不要对仓库根目录直接执行发布；应发布经过检查的正式输出目录。

最终交付是 DSH 原生 npm bundle：宿主入口、客户端 JavaScript、资源、locale、图标与 `cordis.patch.yml`。开发时用 `link:`，测试时用 `.tgz` 或含构建产物的 Git 标签，正式版可发布 npm。当前清单保留 `private: true`；未执行任何公开发布。

React 由 DSH 浏览器模块表提供，未打包第二份 React。构建用 esbuild 将 TS/TSX 编译为 DSH 的 `window.__ModuleLoader__.load` 格式。图片直接包含在客户端资源内，预览不依赖外部图片或 CDN。

```powershell
npm test
npm run typecheck
```

测试覆盖抽选、冷却衰减、各运行阶段连续计时、随机时长范围及分数偏置、入场计时边界、隐藏页面、连续去重、取消竞态、字符分段和数据结构。后续正式模式需额外比较与标准模式的工具、技能及系统提示词，并完成目标桌面版本的联调。

测试宿主为 `0.2.1-rc.3` 源码 Web 实例。深色主题使用宿主的文字与背景变量。
